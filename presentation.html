Vision Model 1: YOLO26n-seg

📋 Model Specifications

  • 🔹 Type: Object Detection + Segmentation
  • 🔹 Variant: YOLO26n-seg (Nano)
  • 🔹 Parameters: 2.7M (lightweight)
  • 🔹 Input Size: 640×640 pixels
  • 🔹 Output: Bounding boxes + pixel masks

🎯 Purpose & Function

  • ✓ Detect oral lesions in images
  • ✓ Segment lesion boundaries (pixel-level)
  • ✓ Provide confidence scores (0-1)
  • ✓ Handle multiple lesions per image
  • ✓ Optimized for edge deployment

⚙️ Processing Pipeline

Input: RGB oral cavity image (any resolution)
Pre-processing: Resize to 640×640, normalize pixel values
Inference: Forward pass through YOLO26n-seg network
Post-processing: NMS (Non-Max Suppression) for detection filtering
Output: Bounding boxes (xyxy format), segmentation masks, confidence scores

Vision Model 2: BiomedCLIP

📋 Model Specifications

  • 🔹 Type: Vision-Language Model
  • 🔹 Architecture: CLIP (Contrastive Learning)
  • 🔹 Backbone: ViT-Base + PubMedBERT
  • 🔹 Training: PubMed medical literature
  • 🔹 Capability: Zero-shot classification

🎯 Classification Classes

  • 🔴 OSCC: Oral Squamous Cell Carcinoma
  • 🟡 OPMD: Oral Potentially Malignant Disorder (leukoplakia)
  • 🟢 Normal: Healthy oral mucosa

⚙️ Zero-Shot Classification Process

Input: Cropped lesion patches from YOLO detections
Text Prompts: Medical descriptions (e.g., "clinical photograph of oral squamous cell carcinoma")
Encoding: Image → Visual features, Text → Semantic features
Similarity: Cosine similarity between image and text embeddings
Output: Class probabilities via softmax (OSCC, OPMD, Normal)

Score Fusion & Clinical Decision Tree

🔀 Fusion Module

Formula: final_score = yolo_confidence × biomedclip_max_score

Purpose: Combines spatial detection confidence with semantic classification confidence
Example: YOLO detects lesion with 0.85 confidence + BiomedCLIP classifies as OSCC with 0.92 score = 0.782 fusion score

🌳 Clinical Decision Tree

Step 1: Start with vision score × 10
Step 2: Add risk factors:
• Age > 40 years → +1.5 points
• Tobacco use > 10 years → +2.0 points
• Lesion duration > 6 weeks → +1.5 points
Step 3: Risk Stratification:
🔴 HIGH (score > 8.0): Urgent referral within 2 weeks
🟡 MEDIUM (score 5.0-8.0): Non-urgent referral within 4 weeks
🟢 LOW (score < 5.0): Routine monitoring recommended

Real-Time Processing Flow

Step 1: Image Acquisition

Smartphone captures oral cavity photo → Upload via Streamlit interface

Step 2: Preprocessing

Resize to 640×640 → Normalize pixel values → Convert to tensor format

Step 3: YOLO Detection (~60ms)

Detect lesions → Generate bounding boxes → Create segmentation masks → Confidence scores

Step 4: Lesion Classification (~150ms per lesion)

Crop detected regions → Encode with BiomedCLIP → Compare with medical prompts → Class probabilities

Step 5: Score Fusion

Multiply YOLO confidence × BiomedCLIP score → Generate fusion score per lesion

Step 6: Clinical Decision

Apply decision tree with patient metadata → Calculate risk score → Determine risk level & referral

Step 7: Output Generation

Visualize detections → Display risk assessment → Show recommendations → Total time: <500ms
